Copien y peguen estas 4 lineas para subir su progreso al github 
lo de git status es opcional, es para ver especificaciones de archivos modificados y cosas asi. 
No es necesario para subir. el commit es un comentario que saldra en la actualizacion de github,

=============opcional===============
git status 
==========obligatorio=========
git pull --rebase (Primero esto por individual) (se añadio el --rebase para evitar errores)
git add .
git commit -m "actualizacion"
git push
